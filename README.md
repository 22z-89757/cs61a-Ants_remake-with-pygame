 **<center>Image Source : CS61A project——Ants</center>**

### 1.Before You Start

Ensure your computer has Python installed and the Pygame library is set up.

- Install Pygame via command line:

      pip install pygame

    Or

      python -m pip install pygame

### 2.Run the Game

- 1.Navigate to the project root directory ( cs61a-Ants_remake-with-pygame/ ).

- 2.Execute the following command to launch:

      python main.py

    Or directly run the `main.py` file
